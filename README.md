## 🕸️ Sobre mí

Profesional de *TI y Ciberseguridad* con un enfoque dual: mantener la *operación estable* y *reducir el riesgo* de forma medible. Trabajo sobre toda la red, desde el host hasta el punto de acceso, buscando puntos débiles antes de que alguien más los encuentre.

<tr>
<td width="33%" valign="top">

</td>
<td width="33%" valign="top">

### 🔒 Endurecer
*Hardening* de Windows Server, aislamiento de secretos con *Credential Guard* y políticas *GPO*.

</td>
<td width="33%" valign="top">

### 🌐 Sostener
Parcheo centralizado con *WSUS* y aseguramiento de red local, *Capa 2* y Wi-Fi.
